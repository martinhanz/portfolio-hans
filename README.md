# Maintenance Portfolio

File `content.js` adalah tempat untuk memperbarui isi portfolio.

Yang bisa diubah di sana:

- Nama dan headline
- Deskripsi profil
- Lokasi, IPK, fokus, dan bahasa
- Pendidikan
- Sertifikasi dan detail pelatihan
- Tugas akhir
- Hard skills, soft skills, dan bahasa
- Kontak WhatsApp, email, LinkedIn
- Teks footer

Jangan ubah struktur HTML utama untuk memperbarui data profil. Pastikan folder `maintenance` tetap berada satu folder dengan `portfolio martin.html` agar file JavaScript tetap terbaca.
